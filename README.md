# SkillBridge Japan 🇯🇵

### Preserving Knowledge. Empowering Japanese SMEs.

## 📌 About the Project

SkillBridge Japan is a frontend web application designed to help Japanese small and medium-sized enterprises (SMEs) preserve and organize practical workplace knowledge.

Experienced employees often possess valuable troubleshooting knowledge that may be lost when they retire or leave the company. This project provides a simple digital library where employees can record, search, and access solutions to workplace problems.

## 🎯 Objectives

- Preserve employees' practical knowledge and experience.
- Make troubleshooting information easy to find.
- Support knowledge sharing in the workplace.
- Provide an interface in English and Japanese.

## ✨ Features

- 📊 Dashboard with knowledge statistics
- 📝 Add and save knowledge articles
- 🔍 Search articles by title, equipment, or error code
- 🌐 English and Japanese interface
- 💾 Browser-based data storage using LocalStorage
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Add knowledge articles and explore the dashboard.

You can also use the Live Server extension in VS Code.

## ⚠️ Current Limitations

- Knowledge articles are stored in the browser's LocalStorage.
- Data is not shared across different users or devices.
- The current version is frontend-only and does not use a backend database.

## 🔮 Future Enhancements

- Backend integration using Java and Spring Boot
- MySQL database for centralized knowledge storage
- Employee authentication and role-based access
- Knowledge article approval and version control
- Improved Japanese-language support
